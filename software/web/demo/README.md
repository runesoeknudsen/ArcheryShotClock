# Browser demo

This folder is a full shot clock that runs in a web browser. It uses the same
C++ core as the ESP32, compiled to WebAssembly. There is no board and no
Wi-Fi. Share the URL so people can tap the buttons and see the firmware panel.

The firmware page in `software/web/index.html` is unchanged. This demo is not copied
into flash.

## What you can try

- Field page: only the next legal press, named for the athletes
  (Start Shoot AB, Start Shoot CD, Score, Emergency)
- Setup page: the timing program and a live preview of occupy / shoot / score
- Start, occupy 10 s, shoot, stop, score
- The LED grid is the real firmware frame, including colour
- **Panel size** and **format** select the same 32×16, 64×32, 96×64 and 128×64
  layouts the ESP32 and Waveshare HUB75 builds use, including extra stacked
  lines in vertical format
- **On-screen LED size** defaults to the browser width; the slider goes down to half a pixel
- **Module pitch** scales the preview cells (P5 is 5 mm) and the millimetre readout
- Beeps play in the browser speaker (after the first tap)

## Run locally

`core.js` and `core.wasm` are generated by `software/tools/build_wasm.sh` and
committed so you can open the demo without Emscripten. Rebuild them after
changing `software/firmware/src/core/` or `software/firmware/src/browser/`.

```text
source /opt/emsdk/emsdk_env.sh   # only needed to rebuild the core
./software/tools/build_wasm.sh
python3 -m http.server 4173 --directory software/web
```

Open `http://127.0.0.1:4173/demo/`.

Do not open `index.html` as a file. The browser will refuse to load
`core.wasm`.

## Share the demo

CI attaches `playwright-artifacts` on every run. The demo is inside that
zip at `test-results/browser-demo/`.

For a public URL: Settings → Pages → Deploy from a branch → this branch
→ `/docs`. Then open
`https://runesoeknudsen.github.io/ArcheryShotClock/`.

`software/tools/sync_pages.sh` copies this folder into `docs/` after a WASM rebuild.
